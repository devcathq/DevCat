What's in the window

Everything a project needs is a tab away, and DevCat keeps each project's connections, chats and repos together. The docs explain each part step by step.

Any coding agent, in a real terminal

Claude Code by default, or OpenAI Codex, Gemini CLI, GitHub Copilot, Aider, opencode or your own CLI. DevCat runs the one you installed, with your own login.

Sessions are listed per project, so you can pick up yesterday's conversation in a click.

See what the agent changed

The Diff tab shows every change as it happens. Tick the files to commit and discard the rest.

Ask for a code review before you commit.

Every repo in a folder

DevCat finds nested repositories and shows the commit graph, blame, branches, tags and stashes.

Fetch, pull and push from the same window.

Your databases, with a proper SQL editor

PostgreSQL, MySQL and MariaDB, SQLite, SQL Server, MongoDB and Redis. Browse and edit tables, compare schemas and move data between them.

Connections go through SSH tunnels when they need to, and passwords stay in your system keychain.

Clusters and queues

Kubernetes with any kubeconfig context: workloads, logs, a shell in any pod, port forwards and Helm releases. RabbitMQ through its management API.

VPNs and SSH tunnels

OpenVPN, WireGuard and SSH forwards, including a SOCKS proxy, with live traffic for each.

Answer your agent from your phone

DevCat Mobile for Android and iPhone gets a notification when an agent needs you, and lets you reply, run a query or check a pod.

It reaches your computer directly or through a relay that only passes encrypted traffic. There's no account to create.

Install

Pick an installer from the latest release, or use a terminal. The scripts check the download's SHA-256 and install for your user only. New to DevCat? Start with First steps.

The app

Only the CLI

For servers and SSH sessions: devcat serve shares your agents and connections with DevCat Mobile or a browser, without a window.

DevCat is built in the open on GitHub. It needs no account and talks only to the tools and connections you set up.

# Keyboard shortcuts

Every shortcut in one place. On Windows and Linux, ⌘ is Ctrl and ⌥ is Alt.

## App

| Action | macOS | Windows, Linux |
| --- | --- | --- |
| Hide or show the sidebar | <kbd>⌘B</kbd> | <kbd>Ctrl+B</kbd> (not inside a terminal) |
| New window | <kbd>⇧⌘N</kbd> | <kbd>Ctrl+Shift+N</kbd> |

## AI workspace

| Action | macOS | Windows, Linux |
| --- | --- | --- |
| Chat view | <kbd>⌥⇧⌘1</kbd> | <kbd>Ctrl+Alt+Shift+1</kbd> |
| Diff view | <kbd>⌥⇧⌘2</kbd> | <kbd>Ctrl+Alt+Shift+2</kbd> |
| Code Review view (Claude Code) | <kbd>⌥⇧⌘3</kbd> | <kbd>Ctrl+Alt+Shift+3</kbd> |
| New terminal in the same folder | <kbd>⌥⇧⌘T</kbd> | <kbd>Ctrl+Alt+Shift+T</kbd> |
| Commit (in the Diff view's message box) | <kbd>⌘↵</kbd> | <kbd>Ctrl+Enter</kbd> |
| Save a file in the editor | <kbd>⌘S</kbd> | <kbd>Ctrl+S</kbd> |

## Terminal

| Action | macOS | Windows, Linux |
| --- | --- | --- |
| Copy the selection | <kbd>⌘C</kbd> | <kbd>Ctrl+Shift+C</kbd> |
| Paste | <kbd>⌘V</kbd> | <kbd>Ctrl+Shift+V</kbd> |
| Clear | <kbd>⌘K</kbd> | <kbd>Ctrl+Shift+K</kbd> |
| Select all | <kbd>⌘A</kbd> | <kbd>Ctrl+Shift+A</kbd> |
| Bigger, smaller, default font size (also in a Kubernetes pod shell) | <kbd>⌘=</kbd> <kbd>⌘-</kbd> <kbd>⌘0</kbd> | <kbd>Ctrl+=</kbd> <kbd>Ctrl+-</kbd> <kbd>Ctrl+0</kbd> |
| New line in the agent's prompt | <kbd>⇧↵</kbd> | <kbd>Shift+Enter</kbd> |

## SQL editor

| Action | macOS | Windows, Linux |
| --- | --- | --- |
| Run the statement under the cursor (or the selection) | <kbd>⌘↵</kbd> | <kbd>Ctrl+Enter</kbd> |
| Run everything | <kbd>⇧⌘↵</kbd> | <kbd>Ctrl+Shift+Enter</kbd> |
| Explain the statement | <kbd>⌘E</kbd> | <kbd>Ctrl+E</kbd> |
| Format SQL | <kbd>⇧⌥F</kbd> | <kbd>Shift+Alt+F</kbd> |
| Save the query | <kbd>⌘S</kbd> | <kbd>Ctrl+S</kbd> |

## Data grid and tables

| Action | macOS | Windows, Linux |
| --- | --- | --- |
| Select all rows | <kbd>⌘A</kbd> | <kbd>Ctrl+A</kbd> |
| Copy (tab-separated) | <kbd>⌘C</kbd> | <kbd>Ctrl+C</kbd> |
| Copy with the header row | <kbd>⇧⌘C</kbd> | <kbd>Ctrl+Shift+C</kbd> |
| Commit pending changes | <kbd>⌘S</kbd> | <kbd>Ctrl+S</kbd> |
| Delete the selected rows | <kbd>⌘⌫</kbd> | <kbd>Ctrl+Delete</kbd> |
| Reload the table | <kbd>⌘R</kbd> or <kbd>F5</kbd> | <kbd>Ctrl+R</kbd> or <kbd>F5</kbd> |
| Save in the table designer | <kbd>⌘S</kbd> | <kbd>Ctrl+S</kbd> |

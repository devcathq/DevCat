# Appearance and fonts

Pick a theme, make the window see-through, and choose the fonts and sizes for terminals and editors.

Click the palette icon in the title bar to open **Appearance**.

## Theme

- **Mode**: dark, light or follow the system.
- **Theme**: 8 dark and 3 light color themes. Editors and terminals follow the theme.
- A project can have a look of its own (**This project**), so you can tell windows apart at a glance.

## Window glass (macOS and Windows)

Turn on **window glass** to let the desktop show through the sidebar and the work area, blurred. Each has its own
opacity slider.

## Fonts

The **Fonts** section applies to every project and window on this computer.

| Setting | What it changes |
| --- | --- |
| **Code font** | Terminals and editors. Type a name, or pick one of the monospaced fonts installed on your computer (JetBrains Mono, bundled with DevCat, is first) |
| **Terminal size** | Font size in terminals (8–32) |
| **Line height** | Space between terminal lines |
| **Editor size** | Font size in editors; empty uses each editor's own size |
| **UI font** | Menus, lists and buttons. The list shows every font installed on your computer |

**Default fonts** puts everything back.

DevCat ships with JetBrains Mono, so terminals look the same on every computer without installing anything, plus
DejaVu Sans Mono for symbols other fonts lack (like those in Claude Code's status line).

> **Tip:** In a terminal, <kbd>⌘=</kbd> / <kbd>⌘-</kbd> / <kbd>⌘0</kbd> (<kbd>Ctrl</kbd> on Windows and Linux)
> change the terminal size directly, for every terminal.
